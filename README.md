# تأسیسات با مهندس ناظری — Android UI

این پروژه یک UI واقعی Jetpack Compose برای اپ آموزشی «تأسیسات با مهندس ناظری» است.

## اجرا
1. پوشه را در Android Studio باز کنید.
2. Gradle Sync را انجام دهید.
3. روی Emulator یا گوشی Android اجرا کنید.

این نسخه UI است و هنوز API/دیتابیس/اعلان روزانه به آن متصل نشده‌اند.
